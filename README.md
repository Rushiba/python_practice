# Python Practice & Core Fundamentals

A structured collection of Python scripts covering core programmatic concepts, object-oriented programming (OOP), data structures, and fundamental algorithms.

## Topic Breakdown

| Script | Core Concept / Topic | Key Features |
| :--- | :--- | :--- |
| `bank_account_oop.py` | Object-Oriented Programming | Encapsulation, private attributes, deposit/withdrawal logic |
| `player_inheritance.py` | Object-Oriented Programming | Class inheritance, method overriding, polymorphism |
| `student_sorting.py` | OOP & Data Structures | Custom object sorting using key functions and `lambda` |
| `linear_search.py` | Searching Algorithms | Searching elements and tracking index positions |
| `factorial_recursion.py` | Algorithmic Logic | Direct recursive function implementation |
| `leap_year.py` | Conditional Logic | Modulo operator conditional checks |

---
## Concepts Covered
* **OOP**: Classes, Instances, Encapsulation, Inheritance, Polymorphism
* **Algorithms**: Linear Search, Recursive Functions, Custom Key Sorting
